# Documentação do Invest Dashboard

Consulte o [índice da documentação](INDEX.md) para navegar pelos requisitos registrados, arquitetura, ADRs, planos e guias existentes.

O processo atual de documentação e implementação está em [conductor/workflow.md](../conductor/workflow.md); os modelos ficam em [templates/](../templates/README.md). Os documentos antigos deste diretório foram mantidos como material histórico. Sua presença não confirma que premissas, regras de negócio ou planos ainda sejam válidos.

Os ADRs existentes estão em [adrs/](adrs/), que permanece a localização canônica para novos registros. Essa escolha evita uma estrutura paralela e não exige mover os ADRs históricos. Crie uma pasta para relatórios separados de validação somente quando o primeiro relatório for necessário.
